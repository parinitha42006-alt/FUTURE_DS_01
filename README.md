# FUTURE_DS_01
# 📊 Business Sales Dashboard from E-Commerce Data

## 🌟 Internship Task 1 – Future Interns | Data Science & Analytics Track

This project is part of my Data Science & Analytics internship with [Future Interns](https://futureinterns.com/). The objective was to analyze cleaned e-commerce sales data and create an interactive dashboard using Power BI.

---

## ✅ Objective

- Identify *best-selling products*
- Track *sales trends* over time
- Analyze *category-wise revenue*
- Present findings in an *interactive business dashboard*

---

## 🧰 Tools Used

- *Power BI* – Data modeling, visualizations, DAX
- *Microsoft Excel* – Initial data exploration
- *GitHub* – Task documentation

---

## 📈 Key Visualizations

- 📊 *Line Chart* – Sales trend by date
- 🏆 *Bar Chart* – Top-performing products by revenue
- 🧩 *Treemap/Pie Chart* – Revenue distribution by category
- 🔎 *Slicers/Filters* – Enable dynamic interaction for product, category, or date filtering

---

## 📌 Skills Gained

- Data cleaning & transformation
- DAX functions & calculated fields
- Business storytelling through dashboards
- Interactive dashboard design principles
